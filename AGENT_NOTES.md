
Agent Notes

This repository contains only the 1D LED strip color shooter.

Do not mix 16x16 matrix game code into this repository.

Priorities:

Preserve the current playable strip game.
Keep hardware pin mappings explicit and configurable.
Separate input actions from physical input devices.
Avoid assigning special attack to normal rapid double-tap.
Make gamepad and phone control future additions map to the same action layer.

Patch delivery should include:

what changed
why it changed
similar existing functionality
regression risk
performance impact
validation steps
rollback guidance
